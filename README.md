# คู่มือติดตั้ง ระบบงานประจำวัน The Second Hatyai

ระบบนี้มี 3 ส่วนทำงานร่วมกัน

| ส่วน | ทำหน้าที่ |
|---|---|
| **Google Sheet** + Apps Script | เก็บรายการงาน รายชื่อพนักงาน บันทึกการส่งงาน และเก็บรูปลง Google Drive |
| **แอปบน Vercel** | หน้าจอให้พนักงานดูงานและถ่ายรูปส่ง, หน้าแอดมิน, ส่งแจ้งเตือนเข้าไลน์ตามเวลา |
| **LINE OA** | บอทในกลุ่มพนักงาน + ปุ่มเมนูเปิดแอป |

ใช้เวลาติดตั้งประมาณ 1–1.5 ชั่วโมง ทำตามลำดับขั้นตอนด้านล่าง

> 💡 ระหว่างทำ ให้เปิดไฟล์ Notes ไว้จดค่าต่าง ๆ ที่ได้ (มีทั้งหมด 9 ค่า ดูขั้นที่ 6)

---

## ขั้นที่ 1 — Google Sheet

1. อัปโหลดไฟล์ `TheSecond_รายการงาน.xlsx` ขึ้น Google Drive
2. ดับเบิลคลิกเปิด แล้วเลือก **ไฟล์ → บันทึกเป็น Google ชีต** (จะได้ไฟล์ Google Sheet ตัวใหม่ ใช้ตัวนี้ตลอด)
3. เช็กว่ามีแท็บครบ: `รายการงาน` `พนักงาน` `ตั้งค่า` `บันทึกส่งงาน`
4. แก้แถวสีส้มในแท็บ `รายการงาน` ให้ถูกต้อง และใส่ชื่อพนักงานคนที่ 6 ในแท็บ `พนักงาน`

⚠️ ห้ามเปลี่ยนชื่อแท็บ และห้ามสลับลำดับคอลัมน์ เพราะแอปอ่านตามตำแหน่ง

## ขั้นที่ 2 — Apps Script (หลังบ้านใน Google Sheet)

1. ใน Google Sheet: **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `apps-script/Code.gs`
3. บรรทัด `const SECRET = 'เปลี่ยนเป็นรหัสลับของคุณ';` เปลี่ยนเป็นรหัสลับยาว ๆ เช่น `ts2-k9Hq4mZ7xWp2Lr8v` → **จดไว้ = APPS_SCRIPT_SECRET**
4. กด 💾 บันทึก
5. ด้านบนเลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้ (Run)**
   - จะมีหน้าขอสิทธิ์ → เลือกบัญชีของคุณ → ขั้นสูง (Advanced) → ไปที่ ... (ไม่ปลอดภัย) → อนุญาต
   - ปกติสำหรับสคริปต์ที่เขียนเอง ไม่ต้องตกใจ
   - ระบบจะสร้างโฟลเดอร์ "The Second - รูปส่งงาน" ใน Drive และใส่ลิงก์ในแท็บ `ตั้งค่า` ให้
6. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: ⚙️ → **เว็บแอป (Web app)**
   - Execute as: **Me (ตัวคุณ)**
   - Who has access: **Anyone (ทุกคน)**
   - กด Deploy → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) → **จดไว้ = APPS_SCRIPT_URL**

> ถ้าภายหลังแก้โค้ด Apps Script ต้องไปที่ **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ทุกครั้ง ไม่งั้นแอปยังใช้โค้ดเก่า

## ขั้นที่ 3 — LINE Messaging API (บอท)

1. เข้า [LINE Official Account Manager](https://manager.line.biz) → เลือก OA ของร้าน
2. **ตั้งค่า (Settings) → Messaging API → เปิดใช้ Messaging API** → เลือก/สร้าง Provider (เช่น "Niban and Friends")
3. เข้า [LINE Developers Console](https://developers.line.biz/console/) → Provider เดิม → channel ของ OA
   - แท็บ **Basic settings** → **Channel secret** → **จดไว้ = LINE_CHANNEL_SECRET**
   - แท็บ **Messaging API** → ล่างสุด **Channel access token (long-lived)** → Issue → **จดไว้ = LINE_CHANNEL_ACCESS_TOKEN**
4. กลับไปที่ OA Manager → **ตั้งค่า → การตอบกลับ (Response settings)**
   - ข้อความตอบกลับอัตโนมัติ (Auto-reply): **ปิด**
   - Webhook: ตอนนี้ยังเปิดไม่ได้ (ต้องมี Webhook URL ก่อน) → ข้ามไปทำในขั้นที่ 7
5. **ตั้งค่า → ตั้งค่าบัญชี** → อนุญาตให้บัญชีเข้าร่วมกลุ่ม: **เปิด**

## ขั้นที่ 4 — LINE Login + LIFF (หน้าแอปที่เปิดในไลน์)

1. ใน LINE Developers Console → **Provider เดียวกับขั้นที่ 3** (สำคัญมาก ถ้าต่าง Provider ระบบจะจำพนักงานไม่ได้)
2. **Create a new channel → LINE Login**
   - App types: เลือก **Web app**
   - กรอกชื่อ เช่น "The Second Tasks"
3. แท็บ **Basic settings** → **Channel ID** → **จดไว้ = LINE_LOGIN_CHANNEL_ID**
4. แท็บ **LIFF → Add**
   - LIFF app name: งานประจำวัน
   - Size: **Full**
   - Endpoint URL: ใส่ `https://example.com` ไปก่อน (กลับมาแก้ในขั้นที่ 7)
   - Scopes: ติ๊ก **openid** และ **profile**
   - Bot link feature: **On (Normal)**
   - กด Add → คัดลอก **LIFF ID** (รูปแบบ `2000000000-AbCdEfGh`) → **จดไว้ = NEXT_PUBLIC_LIFF_ID**
5. ด้านบนของ channel เปลี่ยนสถานะจาก **Developing → Published** (ถ้าไม่ทำ พนักงานจะเปิดแอปไม่ได้)

## ขั้นที่ 5 — นำโค้ดขึ้น GitHub

Vercel จะดึงโค้ดจาก GitHub และอัปเดตแอปให้อัตโนมัติทุกครั้งที่แก้โค้ด

1. สมัครฟรีที่ [github.com](https://github.com/signup)
2. กด **+ → New repository** → ชื่อ `thesecond-tasks` → เลือก **Private** → Create
3. ในหน้า repo กด **uploading an existing file**
4. แตกไฟล์ `thesecond-tasks.zip` แล้วลาก**ทุกไฟล์และโฟลเดอร์ข้างใน** (ไม่ใช่ตัวโฟลเดอร์นอกสุด) ไปวาง → Commit changes

## ขั้นที่ 6 — Deploy บน Vercel

1. เข้า [vercel.com](https://vercel.com) → **Add New → Project → Continue with GitHub** → อนุญาตให้เห็น repo `thesecond-tasks` → **Import**
2. เปิดหัวข้อ **Environment Variables** แล้วใส่ทีละค่า:

| Name | ค่า |
|---|---|
| `NEXT_PUBLIC_LIFF_ID` | จากขั้นที่ 4 |
| `LINE_LOGIN_CHANNEL_ID` | จากขั้นที่ 4 |
| `LINE_CHANNEL_ACCESS_TOKEN` | จากขั้นที่ 3 |
| `LINE_CHANNEL_SECRET` | จากขั้นที่ 3 |
| `APPS_SCRIPT_URL` | จากขั้นที่ 2 |
| `APPS_SCRIPT_SECRET` | จากขั้นที่ 2 |
| `CRON_SECRET` | ตั้งเองเป็นตัวอักษรยาว ๆ เช่น `cr-8sJd2Kq9Lm4Xz` |
| `LINE_GROUP_ID` | เว้นไว้ก่อน (ได้ในขั้นที่ 8) |
| `LINE_ADMIN_USER_IDS` | เว้นไว้ก่อน (ได้ในขั้นที่ 8) |

3. กด **Deploy** รอ 1–2 นาที → จะได้ URL เช่น `https://thesecond-tasks.vercel.app` → **จดไว้**

## ขั้นที่ 7 — เชื่อม LINE กับ Vercel

1. LINE Developers → channel **LINE Login** → แท็บ LIFF → แก้ **Endpoint URL** เป็น URL ของ Vercel เช่น `https://thesecond-tasks.vercel.app`
2. LINE Developers → channel **Messaging API** → แท็บ Messaging API
   - **Webhook URL**: `https://thesecond-tasks.vercel.app/api/line/webhook`
   - กด **Verify** ต้องขึ้น Success
   - **Use webhook**: เปิด
3. OA Manager → **ตั้งค่า → การตอบกลับ** → **Webhook: เปิด** (ตอนนี้จะกดได้แล้ว)

## ขั้นที่ 8 — หา Group ID และ User ID แอดมิน

1. สร้างกลุ่มไลน์พนักงาน (หรือใช้กลุ่มเดิม) แล้ว **เชิญ LINE OA เข้ากลุ่ม**
2. บอทจะทักพร้อมบอก **Group ID** (ขึ้นต้นด้วย `C`) → ถ้าไม่ทัก ให้พิมพ์ `myid` ในกลุ่ม
3. แอด OA เป็นเพื่อน แล้วพิมพ์ `myid` ในแชตส่วนตัวกับบอท → ได้ **User ID** ของคุณ (ขึ้นต้นด้วย `U`)
4. Vercel → Project → **Settings → Environment Variables** เพิ่ม
   - `LINE_GROUP_ID` = Group ID
   - `LINE_ADMIN_USER_IDS` = User ID ของคุณ (ถ้ามีผู้จัดการด้วย ใส่คั่นด้วย `,`)
5. **Deployments → ⋯ ของอันล่าสุด → Redeploy** (ต้อง redeploy ทุกครั้งที่แก้ค่า)

## ขั้นที่ 9 — ปุ่มเมนูให้พนักงาน

1. OA Manager → **ริชเมนู (Rich menus) → สร้าง**
2. เลือกเทมเพลต 1–2 ช่อง
   - ช่อง "ส่งงาน": Action = **ลิงก์** → `https://liff.line.me/LIFF_ID` (ใส่ LIFF ID ของคุณ)
   - (ถ้ามี 2 ช่อง) ช่อง "งานวันนี้": Action = **ข้อความ** → `งานวันนี้`
3. ตั้งให้แสดงตลอด → บันทึก
4. ให้พนักงานทุกคน**แอด OA เป็นเพื่อน** ถึงจะเห็นเมนู

## ขั้นที่ 10 — ทดสอบ

1. เปิดลิงก์นี้ในเบราว์เซอร์ (ใส่ URL และ CRON_SECRET ของคุณ):
   `https://thesecond-tasks.vercel.app/api/cron/morning?key=CRON_SECRET`
   → ในกลุ่มจะมีข้อความรายการงานวันนี้ (ใช้โควตาเท่ากับจำนวนคนในกลุ่ม)
2. กดเมนู "ส่งงาน" ใน OA → เลือกชื่อ → ลองถ่ายรูปส่ง 1 งาน
3. เช็กว่ารูปเข้าโฟลเดอร์ Drive และมีแถวใหม่ในแท็บ `บันทึกส่งงาน`
4. เปิด `https://liff.line.me/LIFF_ID/admin` → เห็นหน้าแอดมิน

✅ เสร็จแล้ว ระบบจะทำงานเองทุกวัน

## ใช้งานประจำวัน

**พนักงาน**
- ครั้งแรก: กดเมนู "ส่งงาน" → เลือกชื่อตัวเอง (ครั้งเดียว)
- ทุกวัน: เปิดแอป → เห็นเฉพาะงานของตัวเอง + งานประจำวัน → กด 📷 ถ่ายรูปส่งงาน
- งานที่ทำ 2 คน: คนใดคนหนึ่งส่งรูปก็นับว่าเสร็จ

**คำสั่งพิมพ์ในกลุ่ม** (บอทตอบกลับ ไม่เสียโควตา)
- `งานวันนี้` / `งานพรุ่งนี้` — ดูรายการงาน
- `ส่งงาน` — บอทส่งลิงก์แอปให้
- `myid` — ดู User ID / Group ID

**แอดมิน**
- หน้าแอดมิน: `https://liff.line.me/LIFF_ID/admin` ดูย้อนหลังได้ทุกวัน มีรูปทุกงาน
- ทุกคืนได้สรุปส่วนตัวว่างานไหนยังไม่ส่ง
- เพิ่ม/แก้งาน: แก้ในแท็บ `รายการงาน` ได้เลย มีผลทันที (ดูวิธีในแท็บ `วิธีใช้`)
- พนักงานเปลี่ยนมือถือ/บัญชีไลน์: ลบค่าในคอลัมน์ LINE userId ของคนนั้น แล้วให้เลือกชื่อใหม่
- พนักงานลาออก: ช่องสถานะ เปลี่ยนเป็น `ไม่ใช้งาน`

## เวลาแจ้งเตือน

ตั้งในไฟล์ `vercel.json` (เวลาเป็น UTC = เวลาไทย − 7 ชั่วโมง)

| ต้องการ (เวลาไทย) | ใส่ใน schedule |
|---|---|
| 09:00 | `0 2 * * *` |
| 10:00 (ค่าเริ่มต้นตอนเช้า) | `0 3 * * *` |
| 11:00 | `0 4 * * *` |
| 22:00 | `0 15 * * *` |
| 23:00 (ค่าเริ่มต้นสรุป) | `0 16 * * *` |

แก้ใน GitHub (กดไฟล์ → ✏️ → Commit) Vercel จะ deploy ใหม่เอง

⚠️ แพ็กเกจฟรีของ Vercel รันตามเวลาคลาดเคลื่อนได้ไม่เกิน 1 ชั่วโมง เช่น ตั้ง 10:00 อาจส่งช่วง 10:00–10:59

## โควตา LINE (ฟรี 300 ข้อความ/เดือน)

- แจ้งเตือนเช้าเข้ากลุ่ม: นับตามจำนวนสมาชิกในกลุ่ม × 30 วัน (7 คน ≈ 210)
- สรุปส่วนตัวให้แอดมิน: 30 ต่อแอดมิน 1 คน
- บอทตอบกลับคำสั่งในกลุ่ม และพนักงานส่งงานผ่านแอป: **ไม่นับโควตา**
- ถ้าเพิ่มแอดมินหรือคนในกลุ่ม ให้คำนวณใหม่ไม่ให้เกิน 300

## ข้อควรรู้เรื่องแพ็กเกจ Vercel

แพ็กเกจฟรี (Hobby) ของ Vercel กำหนดให้ใช้สำหรับงานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ ระบบภายในร้านอาหารเข้าข่ายใช้งานทางธุรกิจ ถ้าต้องการใช้ตามเงื่อนไขอย่างถูกต้อง แพ็กเกจ Pro ราคาประมาณ $20/เดือน (และได้ตั้งเวลาแม่นยำระดับนาที)

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| เปิดแอปขึ้น "ยังไม่ได้ตั้งค่า …" | ใส่ Environment Variable ตัวนั้นใน Vercel แล้ว Redeploy |
| "Apps Script ตอบกลับไม่ถูกต้อง" | Deploy Apps Script ใหม่ เช็ก Who has access = Anyone และ URL ลงท้าย `/exec` |
| "รหัสลับไม่ตรงกัน" | SECRET ใน Code.gs กับ APPS_SCRIPT_SECRET ใน Vercel ต้องเหมือนกัน |
| พนักงานเปิดแอปแล้วขึ้น error ของ LINE | LINE Login channel ยังเป็น Developing → เปลี่ยนเป็น Published |
| ลงทะเบียนชื่อไม่ได้ / ชื่อถูกใช้แล้ว | ลบ LINE userId ของชื่อนั้นในแท็บพนักงาน |
| แจ้งเตือนเช้าไม่มา | เช็ก LINE_GROUP_ID, ดู Vercel → Logs, ลองเปิดลิงก์ทดสอบในขั้นที่ 10 |
| Webhook Verify ไม่ผ่าน | เช็ก LINE_CHANNEL_SECRET และ Redeploy แล้วกด Verify อีกครั้ง |
| งานไม่ขึ้นตามสัปดาห์ | เช็ก "วันเริ่มรอบ" ในแท็บตั้งค่า ต้องเป็นวันจันทร์ |
